# Wave 0 T0.1 attempt log, 2026-11-13

## What is proven working
- beanxapo.dll builds (rustc 1.100.0), 269,312 bytes, panic=unwind
- COM: CoCreateInstance(CLSID_{6F2F0B1C-...}, IID_IAudioProcessingObject) returns S_OK
  from an unprivileged PowerShell process (com-test.ps1)
- Registration shape matches what Windows itself uses, verified byte for byte against
  HKCR\AudioEngine\AudioProcessingObjects\{C9453E73-8C5C-4463-9984-AF8BAB2F5447}:
  FriendlyName, Copyright, Major/MinorVersion, Flags, Min/Max in/out connections,
  MaxInstances, NumAPOInterfaces, APOInterface0
- Endpoint write works UNELEVATED with KEY_SET_VALUE only (reg.exe and .NET both fail
  because they ask for KEY_WRITE, which includes CREATE_SUB_KEY that admins lack)
- Endpoint {269fb022-...} (moniteerrrrsss, the current default) carries our CLSID at
  {d04e05a6-...},13 (REG_MULTI_SZ) and the value survives an Audiosrv restart

  components: the Razer endpoint carries
  {c792e395-bd30-472d-9a2f-2783d7faf812},100 = SWD\DRIVERENUM\THXAPOCOMPONENT_...
