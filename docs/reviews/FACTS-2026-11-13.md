## 4. Platform guarantee under test

Equalizer APO 1.4.2 (`EqualizerAPO-x64-1.4.2.exe`, downloaded from SourceForge
today) contains `EqualizerAPO.dll`, extracted with 7-Zip, and:

```
Get-AuthenticodeSignature .\EqualizerAPO.dll
Status: NotSigned
```

Its registration mechanism is the per-endpoint `FxProperties` values quoted
above, documented in its own developer notes. So an unsigned APO DLL registered
that way loads in the engine on stock Windows.
